# EIGHTYTWO

## التشغيل
1. ثبّت Node.js (نسخة 18 أو أحدث): https://nodejs.org
2. افتح الطرفية داخل هذا المجلد وشغّل:

    npm install
    npm run dev

3. افتح الرابط اللي يطلع (غالبًا http://localhost:5173).
   لو تبي تفتحه من الجوال على نفس الواي فاي، استخدم رابط Network اللي يظهر.

## للنشر
    npm run build
مجلد `dist` هو الموقع الجاهز، ارفعه على Netlify أو Vercel أو أي استضافة ملفات ثابتة.

## المحتوى
كل البطاقات والجوائز والعقوبات في `src/game/data.ts`.

## الألعاب الجماعية
يدعم نظام الرومات والمضيف الألعاب التالية:

- برا السالفة
- مافيا
- كود نيمز
- تحدي الحروف
- عدّد
- صح أو خطأ
- من أنا؟
- الكلمة الممنوعة
- تحدي السرعة
- البلوت

### البلوت
تبدأ لعبة البلوت من روم خاص أو عام بعد دخول أربعة لاعبين. يوزع السيرفر 32 ورقة، يقسم اللاعبين إلى فريقين، يختار المضيف الحكم، ثم يتناوب اللاعبون على رمي الأوراق مع تطبيق قاعدة اتباع اللون واحتساب نقاط اللفات.

## الصور
الهوية البصرية تستخدم الصور الموجودة داخل `public/images`، ويمكن تبديل الخلفيات أو الشعار من هناك دون تعديل منطق اللعبة.
